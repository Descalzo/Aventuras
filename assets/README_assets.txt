ASSETS NECESARIOS

Las imágenes deben tener exactamente el mismo encuadre y resolución para que las capas coincidan.

Escena base:
- room_base.webp

Overlays transparentes (mismo tamaño que la escena):
- drawer_open.webp        -> solo el cajón abierto y su interior
- picture_moved.webp      -> cuadro desplazado + caja fuerte cerrada visible
- safe_open.webp          -> caja fuerte abierta
- clock_repaired.webp     -> reloj reparado / mecanismo funcionando
- panel_powered.webp      -> cuadro eléctrico con fusible y luz verde
- door_open.webp          -> puerta abierta + pasillo iluminado

Objetos del inventario con fondo transparente:
- item_small_key.webp
- item_gear.webp
- item_fuse.webp
- item_door_key.webp

RECOMENDACIÓN
Para un resultado realmente profesional, generar primero room_base.webp y después usar esa misma imagen como referencia para crear cada overlay/estado, sin cambiar cámara, perspectiva, iluminación ni posición de los objetos.
